# Features

## StockHub

### Implemented

- Market Overview display on the StockHub Hub screen
- Daily charts for the Nikkei 225, TOPIX-linked ETFs, USD/JPY, NASDAQ, S&P 500, and the U.S. 10-year Treasury yield
- Market data retrieval via the Spring Boot API
- Candlestick charts using Lightweight Charts
- Watchlist sparklines using Recharts

### Planned

The following features are planned:

- Create, view, and edit watchlists
- Search for securities and view basic information
- Custom screening
- Create custom indices
- View custom index performance
- Customize the user interface
- Links to external stock information sites
- Review investment predictions and outcomes (answer-checking feature)
- Record IN / OUT points
- Write investment journals
- Strong-chart detection and chart pattern classification using jev
- Notifications when a specified price is reached


## IndexArena

The following features are planned for the future:

- Performance competitions for custom indices
- Analysis of public sentiment using information such as the index’s highest-weighted constituents
- Organize and share useful investment information
- Reviews that help investors grow
- Evaluate information based on past predictions and actual results
